# Anchor Arcana

A 2D action-adventure tower defense game built with Godot.

## 🎮 Play the demo:
[itch.io/anchor-arcana](https://timmers.itch.io/anchor-arcana)

## Overview

Anchor Arcana began as a game jam project and evolved into a larger exploration-focused adventure game.

## The goal:
Create a world where exploration, combat, and strategic defense combine into a meaningful player-driven experience.

## Features

✅ Character movement system
✅ Keyboard controls
✅ Mobile controller support
✅ Camera follow system
✅ Enemy interactions
✅ Exploration mechanics
✅ Godot scene architecture

## Tech Stack
Godot Engine
GDScript
Git/GitHub
HTML5 export
Mobile testing
